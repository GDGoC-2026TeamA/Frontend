# 로딩, 오류와 빈 상태

Figma `117:2083`의 최신 6개 화면을 기준으로 구현했습니다.

| 화면                   | 진입                                                     | 복구 동작                                               |
| ---------------------- | -------------------------------------------------------- | ------------------------------------------------------- |
| 검토할 초안 로딩       | 홈의 재고 업무 처리하기 → 예시 전표로 확인 → 초안 만들기 | 자료 입력으로, Escape, 닫기에서 처리 취소와 입력값 유지 |
| 전표 읽기 오류         | 예시 전표의 로딩 종료                                    | 다시 시도, 파일 다시 선택                               |
| 비교 자료 부족         | 새 업무 등록에서 기존 자료만 선택하거나 예시 매뉴얼 삭제 | 누락 영역 강조와 매뉴얼 선택, 기존 자료 및 이름 유지    |
| 개인 업무 카드 빈 상태 | `/work-cards`                                            | 업무 선택하기 → 홈                                      |
| 작업 내역 빈 상태      | `/history`                                               | 업무 시작하기 → 홈                                      |
| 홈 검색 결과 없음      | 홈에서 일치하지 않는 검색어 입력                         | 검색어 지우기와 입력 포커스 복귀                        |

## 연결 범위

- `/work/input`은 로딩과 오류를 확인하는 업무 자료 입력 화면입니다. 초안 검토와 결과 저장은 후속 범위입니다.
- ‘예시 전표로 확인’을 누른 경우 1.8초 뒤 고정된 읽기 오류를 표시합니다. 다시 시도도 같은 오류 예시를 보여줍니다.
- 실제 선택한 파일은 읽거나 전송하지 않습니다. 실제 파일에는 분석 연결 전 안내를 표시하고 재시도 버튼을 비활성화합니다.
- 기본 demo 모드의 카드와 작업 내역은 Figma 빈 상태를 확인하는 독립 예시입니다. 홈의 고정 예시 카드와 실제 저장 데이터를 동기화한 목록이 아닙니다.
- api 모드의 목록은 `GET /api/v1/cards`, `GET /api/v1/jobs`를 호출합니다. 성공한 응답의 `items: []`에만 빈 상태를 표시합니다. HTTP 실패나 잘못된 응답은 오류와 다시 시도로 표시하며 예시로 대체하지 않습니다.
- 실제 서버 성공 응답은 확인하지 않았습니다. API 브라우저 검사는 요청을 가로챈 검사 응답을 씁니다.
- 팝업 닫기와 취소는 처리 타이머를 해제합니다. 페이지를 떠나도 타이머가 남지 않습니다. 파일 다시 선택은 전표만 초기화하고 작업 이름과 수량을 유지합니다.
- 기존 공통 Modal의 포커스 유지와 Escape 동작을 재사용하고 상태가 바뀌면 상태 문구로 포커스를 옮깁니다.

## 검사와 캡처

코드 검사와 배포 빌드는 실행했습니다. 현재 에이전트 실행 환경의 로컬 네트워크 제한으로 브라우저 검사는 완료하지 못했습니다. 사용자 터미널의 검사 결과를 확인한 뒤 이 문서를 갱신합니다.

`tests/status-screens.spec.js`는 처리 취소, 입력 보존, 재시도, 실제 파일과 예시 구분, 자료 보충, 빈 목록 복구, 모바일 배치와 접근성을 검사합니다. `tests/home-api.spec.js`는 목록 오류와 빈 응답 및 서버 항목을 구분하는 검사를 포함합니다.

캡처 경로는 `docs/screenshots/status-*.png`입니다. 검사가 성공하기 전에는 캡처 생성이나 브라우저 검사 통과를 보장하지 않습니다.
