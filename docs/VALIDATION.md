# 1차 점검 기록

점검일: 2026-11-20, 한국 시간

환경: Windows, Node.js 24.21.0, npm 11.19.0, 설치된 Microsoft Edge의 headless 브라우저.

| 항목               | 결과                                                                        |
| ------------------ | --------------------------------------------------------------------------- |
| 개발 서버          | Vite 개발 서버에서 홈과 컴포넌트 화면 열림                                  |
| 코드 검사          | `npm run lint` 통과                                                         |
| 배포용 빌드        | `npm run build` 통과                                                        |
| 브라우저 자동 점검 | 6개 시나리오 통과                                                           |
| 자동 접근성 검사   | 홈, 컴포넌트 화면, 모바일 Drawer의 WCAG A와 AA 대상 규칙에서 검출 항목 없음 |

빌드 미리보기에서도 1440×1080 홈, 메뉴, 로컬 아이콘과 직접 주소 접근을 확인했습니다. 개발용 확인 주소는 기본 프로덕션 빌드에서 열리지 않으며 브라우저 실행 오류가 없었습니다.

## 브라우저 점검 범위

1. 주요 메뉴 3개 이동, 현재 메뉴 표시, 새 업무 등록 틀, 없는 주소 안내, 도움말 열기와 닫기.
2. 입력값 변경, 체크박스, 읽기 전용과 비활성, 오류 연결, 방향키 탭 전환과 단계 변경.
3. 파일 선택과 삭제, 끌어놓기, 허용하지 않은 형식과 10MB 초과 검사, 새로고침 초기화. 파일 선택 중 쓰기 요청이 없음을 확인.
4. Modal과 Drawer 열기, 닫기, Escape와 배경 클릭, Tab 순환, 열기 버튼으로 포커스 복귀.
5. 정상 예시, 로딩, 오류, 재시도와 자료 부족 전환.
6. 데스크톱과 390px 모바일 배치, 메뉴 Drawer, 문서 전체의 가로 넘침 여부와 자동 접근성 규칙.

시각 확인에서 비어 있던 Clock PNG를 찾아 원본 SVG로 바꿨습니다. 반복 Tab 조작 중 포커스가 빠지는 문제도 고쳐 다시 검사했습니다.

자동 접근성 검사는 전체 접근성을 보증하지 않습니다. Safari, Firefox, 실제 모바일 기기와 스크린리더는 이번 차수에 검사하지 않았습니다. 실제 API, 파일 업로드와 AI 결과의 정확성은 연결되지 않아 검사 대상에 포함하지 않았습니다.

브라우저 검사 코드는 `tests/foundation.spec.js`에 있습니다. 스크린샷과 trace는 재현 가능한 로컬 점검 산출물이므로 소스 전달 파일과 Git에 포함하지 않습니다.

## 홈 공통 틀 V0.2 수정 후 점검

수정된 `01 · Design System`과 `홈 리디자인 / 파스텔 업무 카드` 프레임을 읽기 전용으로 확인한 뒤 1차 공통 틀을 맞췄습니다. 홈 본문의 실제 업무 카드, 작업 목록과 일러스트는 검사 대상이 아니며 2차에 만듭니다.

- `npm run lint`, `npm run build`, 브라우저 점검 6개 모두 통과.
- 1440×1080에서 흰색 프레임 위치 36×58px, 크기 1368×964px 확인.
- 홈 메뉴 208px, 가운데 열 792px, 오른쪽 영역 368px 확인.
- 홈 제목 42px, 검색 226×42px 확인. 홈에 기존 72px 상단 바가 남아 있지 않음.
- 업무 화면에서는 240px 메뉴와 72px 상단 바 유지 확인.
- 390px 모바일 메뉴와 모달 조작, 홈과 공통 UI의 자동 접근성 검사 통과.
- 320px, 768px, 1024px에서 홈의 문서 가로 넘침 없음.
- 홈 배경, 프레임 모서리와 원본 선 아이콘을 데스크톱과 모바일 캡처에서 확인.

## API 트래커 정합성 수정 (#7)

2026-11-20 한국 시간에 Notion API 작업 트래커의 30개 항목과 각 상세의 요청·응답 예시를 대조했습니다.

- 기본 경로 /api/v1, JSON PATCH와 본문 없는 결과 저장 POST 확인
- 업무 기준 자료와 작업 자료의 multipart 파일 바이트, kind 구분과 브라우저 boundary 확인
- 바이너리 다운로드 바이트와 Content-Disposition 보존, 삭제 204 확인
- HTTP 503과 요청 취소가 오류로 남고 데모 성공으로 바뀌지 않는지 확인

위 API 검사는 Playwright의 요청 가로채기로 실행한 전송 코드 검사입니다. 실제 백엔드 연결이나 서버 동작 검증이 아닙니다. 화면은 예시 모드로 유지합니다.

이번 수정 후 lint와 build가 통과했고, API 전송 4개와 기존 화면 6개를 합친 브라우저 검사 10개가 모두 통과했습니다. 실제 백엔드 대상 검사는 하지 않았습니다.
