- `icons/home.png`: WORK BRIDGE Figma 파일의 `7:111`, Home 아이콘을 그대로 내보낸 PNG.
- `icons/book-open.png`: 같은 파일의 `10:399`, 도움말 Book open 아이콘을 그대로 내보낸 PNG. 메뉴에서는 20px, 도움말에서는 24px로 표시합니다.
